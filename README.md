#       FAIZSEC Backend API

FAIZSEC is a secure backend API built with Flask that demonstrates data integrity, hashing, and basic API design principles.



#       Features

- SHA-256 hashing
- RESTful API design
- Input validation
- JSON responses
- Simple in-memory storage (for demo purposes)



##      Tech Stack

- Python 3
- Flask
